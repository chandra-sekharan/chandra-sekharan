### 🔭 What I'm building

**Axion AI**: an AI-powered IDE that builds frontend web apps from natural-language prompts.
- It plans the app structure, generates each file, installs dependencies and launches a live preview.
- When a build fails, it reads the errors and uses an LLM to write the fix.
- Built with React, TypeScript, Node.js, Express, OpenRouter, Docker and CI/CD, and deployed on OCI.

**Piko**: an AI desktop companion that lives on your desktop.
- You talk to it by voice; it can watch the screen, automate the browser, take notes and set alarms.
- It runs local and cloud LLMs with tool calling for system automation.
- Built with Electron (secure IPC, preload scripts and context bridge), React, TypeScript, LangGraph and Ollama.
